# cml_latch_uhf wiring C — Magic RC [PEX-RC]

## Method
- Tool: Magic + `ihp-sg13g2.magicrc`; flatten cell; `extract all`; keep `.ext` [TOOL].
- Units: Magic `.ext` aF / 1000 = fF.
- **Wiring add** = sum of coupling caps to other nets (= all partners + substrate − substrate/node C). Same bank-method as VCO (`summary_pex_bank`) [PEX-RC].
- Substrate/node C includes diffusion/gate area Magic attributes to the net; device C is in PDK MOSFET / rppd models and is **excluded** from wiring add [PEX-RC / PDK].
- Series R: `extresist` not run [TOOL].
- GDS: `out/cml_latch_uhf.gds` cell `cml_latch_uhf`.
