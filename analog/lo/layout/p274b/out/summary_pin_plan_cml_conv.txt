# cml_conv (lo_converter) pin plan [HAND]

Topology unchanged [SCH]. Leaves accepted. Parent joins: gap stubs only;
no parent metal through a child bbox (assembly_guard). Series cmim: M5=MINUS
/ TM1=PLUS both signal; TM1 stubs w≥1.70 µm (TM1.a), space ≥1.64 µm (TM1.b)
[DS / cbf·hold / bank_unit].

## Floorplan (W→E)

| Region | Cells |
|---|---|
| AC-p (north) | cmim_p → rhigh_p → inv_p (`lo_inv_2_4`) |
| AC-n (south) | cmim_n → rhigh_n → inv_n (`lo_inv_2_4`) |
| XC (east of inv_p/n) | xc_a (`lo_inv_05_1`) north; xc_b (`lo_inv_05_1`) south |
| AC-b + taper | cmim_b → rhigh_b → inv_b (`lo_inv_2_4`) → inv_t3 (`lo_inv_3_6`) → inv_t9 (`lo_inv_9_18` = 2×45_9) |

Gap between N and S rows ≥ 4 µm (corridor for cross stubs). Gap between
east-adjacent bboxes ≥ 4 µm.
