# cml_conv (lo_converter) pin plan [HAND] — VCO island layer rules

Topology unchanged [SCH]. Leaves accepted. Parent join uses VCO island rules
(no parent M1 straps; supplies on own layer; one direction per signal layer).

## Layer plan

| Layer | Direction | Use |
|---|---|---|
| M1 | — | Face stubs / via landings only (≤ 2.5 µm) |
| M2 | H only | Signal horizontals |
| M3 | V only | Signal verticals |
| M4 | H only | vcv (N rail), gnd (S rail) |
| M5/TM1 | cmim | TM1 w≥1.70 / space≥1.64 [DS] |

## Floorplan (W→E)

| Region | Cells |
|---|---|
| AC-p (north) | cmim_p → rhigh_p → inv_p (`lo_inv_2_4`) |
| AC-n (south) | cmim_n → rhigh_n → inv_n (`lo_inv_2_4`) |

## Power

via14 at each inv vcv (N face) / gnd (S face) → M4 H rails. No M1/M2/M3
supply straps between children.

## Signal joins

| net | join |
|---|---|
| face↔face gap | M1 pad + via12 → M2 H → via12 → M1 pad |
| Y jog | M2 H + via23 + M3 V + via23 + M2 H |
| cmim mid | TM1 legal stub → via1t → M1 pad → via12 → M2 |
| cmim input | M5 via → M1 pad → via12 → M2 |
