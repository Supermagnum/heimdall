## Unstacked option (needs owner approval)

**Idea:** remove one series device from the critical path so
V_DD ≥ swing + 2×V_dsat fits in ≈1.11 V.

Concrete variants (pick one if approved):

1. **Tail-less clock pair (already in step1 VARIANT['tailless']):**
   clock devices source to gnd; bias by device W only. Stack becomes
   R_L → data → clock-to-gnd (2-high). Used historically as a speed
   experiment; current and matching change; must re-check noise and
   UHF ÷2 sharing.

2. **Folded / PMOS-load CML latch:** NMOS data+clock over a single
   tail, PMOS active load — classic low-V CML. New cell; more devices;
   needs bias for PMOS; LVS/xschem redo.

3. **Pseudo-diff / current-mode logic with resistive only one switch
   level** (e.g. MCML with fewer stacked gates): larger redesign.

4. **Keep ideal / cascode-biased tail current** from a higher headroom
   bias (e.g. thick-oxide or boosted nbias) so the latch stack sees an
   ideal-like current sink with V_min ≈ 50–80 mV — closer to the
   known-PASS ideal-`isource` case without changing the latch graph.

**Not done here:** no schematic change for (1)–(4) without owner pick.
